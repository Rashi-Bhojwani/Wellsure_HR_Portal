# Synthetic fixtures (safe for a public repo)

These files copy only the COLUMN STRUCTURE of the real greytHR / bank / device files. Every value is made up.
Never commit the real files. They contain real names, account numbers and the company name.

- attlog_sample.dat: device export. 6 tab-separated columns: user id (right-aligned, width 9), timestamp `YYYY-MM-DD HH:MM:SS`, then three numeric flags and one more (observed constant in the real file: 1, 255, 1, 0).
- Attendance_Swipes_template.xlsx: greytHR bulk swipe import. Columns: Access Card number/Employee Number, Employee Name, In/Out Status, Door Name, Date & Time. A footer row says red columns are mandatory.
- Bulk_Salary_Overrides_template.xlsx: Employee Number, Overide From, Overide Till, Principal Part, Interest Part, Remarks, then ONE COLUMN PER INPUT PAY HEAD (incentive, leave encashment, old month discrepancy, slab salary bonus, training exp, loan, salary advance, other deduction, laptop deduction, LOP, and PF-related overrides: EPS basic, EDLI basic, EDLI contribution, EPF admin charges, EDLI admin charges, employer PF full, employer PF perquisite). The pay-head columns depend on how the company configured its heads, so our import must generate its columns from the configured input heads, not hardcode this list.
- Salary_Statement_template.xls: binary .xls. Header block (company name, title) then a header row on row 5: employee, name, department, designation, location, manager, days in month, effective workdays, LOP, basic, HRA, special allowance, gross, one-off earnings, deductions, total deductions, employer PF, net pay, attendance LOP, latest revision date, bank account, IFSC, left flag, leaving date, monthly CTC.
- Bank_Transfer_template.xls: binary .xls bank bulk-transfer template. 21 columns: From A/C No., A/C no., Beneficiary Name, Amount, Payment Mode (single letter code), Date (DD-MON-YYYY), IFSC code, Payable Location, Print Location, Mobile No, Mail ID, Bene Address 1-4, Add Detail 1-5, Remark. The debit account and every code value are owner-entered; never guess them. The bank wants .xls (not .xlsx), so the product needs an .xls writer or the bank must confirm .xlsx/.csv is accepted.
