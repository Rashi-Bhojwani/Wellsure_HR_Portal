# Standard statutory defaults

Generated from `shared/constants/statutoryDefaults.ts` by `npm run docs:statutory-defaults` (pack version 1, values checked on 2026-11-16). Do not edit by hand.

Owner decision 2026-11-16: statutory and tax rules ship with standard, sourced values already in force (plan: `docs/plans/STATUTORY_DEFAULTS_PLAN.md`). A value is used only where no director has **confirmed** a value of their own; the pack never overwrites one. State: Rajasthan. Direct fetches of the government sites were refused (HTTP 403/503) from the build machine, so official documents were read through the search index of the official domains; a value only a non-government site states is marked UNVERIFIED and is still used, flagged "review needed" on the screens and on Ready for First Run.

## Returns

- **PF ECR**: [EPFO, Introduction to Electronic Challan cum Return Version II (ECR 2.0): fields and #~# separator](https://www.epfindia.gov.in/site_docs/PDFs/EPFOUnifiedPortal/Introduction_ECR2.0.pdf). Fields in order: UAN, member name, gross wages, EPF wages, EPS wages, EDLI wages, EE share, EPS contribution, ER share (EPF-EPS difference), NCP days, refund of advances; separator `#~#`; whole rupees; no header. Check against the portal before uploading: EPFO's own help file on the employer portal is the final word on the current layout.
- **ESI monthly contribution upload**: not publicly documented (only the portal's own template). Nothing is built; **an item for the owners to try on the real ESIC portal**.

## Not modelled (named, not guessed)

- ESI: the daily-wage exemption (Rs 176) and the Rs 25,000 ceiling for persons with disability.
- PF: the Rs 500 monthly minimum administrative charge (per establishment); September 2026 uses the ceiling in force on its last day (Rs 25,000).
- Gratuity: one year for fixed-term employees (pro rata).
- Income tax: the old regime's 37% surcharge above Rs 5 crore and marginal relief at surcharge thresholds.
